# AgileFlow System Architecture

AgileFlow is built on a modern MERN (MongoDB, Express, React, Node) stack.

## Frontend
- React 19 & Vite for asset compilation and building.
- Tailwind CSS v4 for UI layouts.
- Dynamic theme contexts (dark/light switchers).

## Backend
- Express.js API framework.
- Mongoose for Atlas connection schemas.
- JWT verification middleware for route protection.
