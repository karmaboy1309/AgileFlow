# AgileFlow Development Setup

Follow these commands to install and start the AgileFlow workspace locally.

## Prerequsites
- Node.js 18+
- MongoDB local community instance or Atlas cloud URI.

## Installation
1. Install server and client dependencies:
   ```bash
   npm install
   ```
2. Set up environmental configuration `.env` in the server root.
3. Start development server:
   ```bash
   npm run dev
   ```
