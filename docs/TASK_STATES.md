# Task Transitions & Status Logic

Task status follows a structured workflow pattern inside the Agile Kanban Board.

## Standard Transition Flow
- **To Do**: Open issues that are not currently being worked on.
- **In Progress**: Work has started.
- **In Review**: Completed code changes needing code review or test sign-off.
- **Done**: Fully completed tasks.

Status modifications are registered into the task activity log history.
